# Summary

build an interactive tool where people can design their dream workspace and then rent it. But here's the thing: the user doesn't want to just click through a boring product catalog. They want a cool, visual, fun experience — pick a desk, choose a chair, throw on some monitors, add a lamp, maybe a plant — and actually see their setup come to life. Then hit "Rent" when they're happy with it.

## Tech Stack 

- Nextjs 
- Tailwindcss
- Typescript
